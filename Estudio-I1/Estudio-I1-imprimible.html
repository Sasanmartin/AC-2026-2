Cheatsheet 1 · Representación de números (P1)

Cheatsheet 1 — Representación de números (P1)

1. Sistema posicional

Un número en base b: cada símbolo vale símbolo × b^k (k = posición desde la derecha, partiendo en 0).

1234 (base 4) = 1·4² + 2·4¹ + 3·4⁰  →  no existe, el 4 no es dígito válido en base 4
0xCAFE = C·16³ + A·16² + F·16¹ + E·16⁰ = 12·4096 + 10·256 + 15·16 + 14 = 51966

2. Conversión rápida (bases potencia de 2)

  • bin → hex: agrupar de a 4 bits (desde la derecha); cada grupo = 1 dígito hex. 1100 1010 1111 1110 = C A F E
  • bin → oct: agrupar de a 3 bits. 110 010 101 111 110 = 6 2 5 7 6
  • dec → bin: divisiones sucesivas por 2, los restos al revés. 13 → 1101
  • bin → dec: sumar potencias de 2 según posición de los 1s.
  • base 8 → base 4 (tipo I1 2025-2): cada dígito oct → 3 bits, agrupar de a 2 bits (agregar 0 a la izquierda si falta), cada grupo → dígito base 4.
  • 712₈ = 111 001 010b → 01 11 00 10 10b = 1,3,0,2,2 → 13022₄

3. Números negativos

Representación Cómo Cero
Signo y magnitud bit MSB = signo 0000 y 1000 (dos ceros)
Complemento 1 (C1) negar todos los bits 0000 y 1111 (dos ceros)
Complemento 2 (C2) C1 + 1 único: 0000
  • C2 resuelve los 3 problemas de signo y magnitud (sin bit de signo propio, suma directa sin paso extra, un solo cero).
  • Desbalanceado: con n bits rango [-2^(n-1), +2^(n-1) − 1] (8 bits: −128..127). Siempre hay un negativo sin su positivo.

4. Cálculo de C2 (de un hex a decimal)

0x8F = 1000 1111b   (MSB = 1 → negativo)
magnitud = C2(10001111) = negar (01110000) + 1 = 01110001 = 113
resultado = −113

5. Overflow y carry

  • Carry (C): bit que sale del bit más significativo en suma/resta (o bit descartado en shift).
  • Overflow (O): resultado fuera del rango de la representación con signo. Depende de los signos:
  • A ≥ 0, B ≥ 0 → O=1 si A+B < 0
  • A < 0, B < 0 → O=1 si A+B ≥ 0
  • A ≥ 0, B < 0 → O=1 si A−B < 0
  • A < 0, B ≥ 0 → O=1 si A−B ≥ 0
  • Carry ≠ overflow: −1 + −2 = (1)1101 en 4 bits → hay carry, no overflow. El carry solo indica overflow en representación sin signo.

6. Extensión de bits (8 → 16)

  • Positivo: rellenar con 0s a la izquierda. Negativo: rellenar con 1s. Mantiene el valor.

7. Número mínimo de bits

x=0 → 1 bit; x>0 → ⌊log2(x)⌋ + 1.

8. Endianness

  • Big endian: bytes MSB primero en memoria. Little endian: bytes LSB primero.
  • 2 bytes big 0x0104 = 260 → little = 0x0401 = 1025.

9. Justificar por qué funciona una conversión directa (tipo I1 2026-1)

Piden justificar con la fórmula Σ sₖ·bₖ por qué hex→bin directo funciona:
- Idea clave: 16 es potencia de 2 (16 = 2⁴), ambas bases son potencia del mismo número.
- Cada dígito hex sₖ · 16ᵏ = sₖ · 2^(4k) → equivale a 4 bits (los dígitos hex 0-F usan 4 bits).
- Ejemplo: 0x12 = 2·16⁰ + 1·16¹ = 2·2⁰ + 1·2⁴ = 0001 0010b. Los "huecos" son los bits 0 que se rellenan.
- Responder: expansión con la fórmula + mostrar que el dígito se descompone en 4 bits → justifica la agrupación.

Ejemplo tipo prueba (I1 2024-1 / clase 01)

0xCAFE en C2 → −13570. Pasos: binario 1100101011111110, MSB=1 → negativo, C2 = 0011010100000010 = 13570 → −13570.

Cheatsheet 2 · Circuitos digitales (P2)

Cheatsheet 2 — Circuitos digitales (P2)

1. Compuertas lógicas básicas

Compuerta Salida = 1 si...
NOT entrada = 0
AND ambas = 1
OR al menos una = 1
XOR ambas distintas
NAND NO(AND) = 0 solo si ambas = 1
NOR NO(OR) = 1 solo si ambas = 0

2. Tabla de verdad → circuito (minterms y maxterms)

Procedimiento fijo para "diseñe el circuito":
1. Hacer la tabla de verdad.
2. Minterms (fila = 1): NOT las variables en 0, AND las de cada fila, OR todas.
3. Maxterms (fila = 0): NOT las variables en 1, OR las de cada fila, AND todas.
4. Simplificar con álgebra booleana si piden circuito reducido.

A B C | Out
0 0 1 |  1      Out = (NOT A AND NOT B AND C)
1 0 1 |  1            OR (A AND NOT B AND C)
1 1 1 |  1            OR (A AND B AND C)

3. Sumador y restador

  • Half Adder (HA): S = A XOR B, Cout = A AND B.
  • Full Adder (FA): dos HA + OR: S = A XOR B XOR Cin, Cout = c1 OR c2.
  • Sumador de n bits: n FA encadenados por Cin.
  • Sumador-Restador: con XOR y Cin como control. Cin=0 → A+B, Cin=1 → A−B (B se niega y se suma 1).
  • Restador: sumar el complemento a 2 del sustraendo.

4. Circuitos de control

  • Enabler: AND con señal E → pasa el dato si E=1, saca 0 si E=0.
  • Multiplexor (Mux): S selecciona entre entradas. 2 a 1: M = (NOT S AND A) OR (S AND B). 4 a 1 usa S1,S0.
  • Demux: S dirige la entrada a una de varias salidas.

5. Flags de la ALU

Z (resultado = 0), N (resultado negativo), C (carry/bit descartado), O (overflow). Se guardan en el registro Status para los saltos.

6. Circuitos secuenciales — Contador con flip-flops D (¡muy frecuente!)

Patrón para contadores de 2 o 3 bits (I1 2024-2, 2025-1, 2025-2):
1. Definir la tabla de verdad del siguiente estado Q(t+1) según el estado Q(t).
2. Derivar la expresión de cada bit (ej. contador que incrementa):
- Q0(t+1) = NOT Q0
- Q1(t+1) = Q0 XOR Q1
- Q2(t+1) = (Q0 AND Q1) XOR Q2
3. Conectar cada salida a su flip-flop D y las compuertas a los D.

Con condición (ej. "incrementa solo si A=1"):
- Q(t+1) = (A AND incrementado) OR (NOT A AND Q(t)) → equivale a un multiplexor con A como selector entre "incrementado" y "actual".
- Para decrementar, Q1(t+1) = Q0 XNOR Q1.

Ejemplo tipo prueba (patrón que cae: contador con condición)

Contador de 2 bits que decrementa y que resetea a 11 si botón B=1:
Q0(t+1) = B OR (NOT Q0), Q1(t+1) = B OR (Q0 XNOR Q1).
Diseñar = flip-flops D + XOR/XNOR + mux/OR para la condición.

Cheatsheet 3 · Almacenamiento de datos (P2)

Cheatsheet 3 — Almacenamiento de datos (P2)

1. Latches y Flip-Flops

Elemento Comportamiento
Latch RS S=1 → Q=1; R=1 → Q=0; S=R=1 → mantiene Q(t); S=R=0 → indefinido
Latch D D=1 y C=1 → Q=1; D=0 y C=1 → Q=0; C=0 → mantiene
Flip-Flop D Solo cambia en el flanco de subida (↑) del clock: Q(t+1) = D. El resto del tiempo mantiene el valor
  • El latch es sensible a nivel; el flip-flop es sensible al flanco (eso resuelve el problema de activarse en un instante preciso).

2. Reloj y registros

  • Reloj = tren de pulsos con ancho e intervalo precisos. Todos los registros de un computador usan el mismo reloj.
  • Registro = conjunto de N flip-flops D (N = bits de la palabra). Tiene control de carga (L) y reset (R):
  • ↑, L=1 → Q = entrada; ↑, L=0 → mantiene.
  • Registro contador: registro + señal Up (suma 1) / Down (resta 1) en cada flanco.

3. Memorias

  • RAM: acceso por dirección (direccionamiento). Palabras de 8 bits típicamente. Permite leer y escribir (WE).
  • 256 celdas = direcciones 00000000 a 11111111 (2^8).
  • RAM de doble puerto (tipo I1 2023-2): dos direcciones de lectura/escritura simultáneas → dos mux para DataOut, dos demux para WE/DataIn, OR por registro.

4. Variables y arreglos

  • Variable: valor temporal con un único tipo, guardado en registros o RAM.
  • Arreglo: variable con 4 atributos → tipo de dato, endianness, largo y dirección de inicio. Se indexa para acceder a cada elemento.

5. Endianness (¡saber calcular!)

  • Dato multibyte almacenado en direcciones consecutivas:
  • Big endian: byte más significativo primero (en la dirección más baja).
  • Little endian: byte menos significativo primero.
  • Ejemplo: int 0x0FA71D23 de 4 bytes:
  • Big: mem[0]=0x0F, mem[1]=0xA7, mem[2]=0x1D, mem[3]=0x23
  • Little: mem[0]=0x23, mem[1]=0x1D, mem[2]=0xA7, mem[3]=0x0F

Ejemplo tipo prueba (I1 2022-1: "La Memoria, Mi Dato...")

Disponible en Interrogaciones/2022-1/IIC2343-2022-1-S2-Memoria-Palindromo.pdf.
Arreglo de 3 enteros sin signo de 16 bits desde la dirección 1, little-endian, palabras de 8 bits:
juntar de a 2 bytes al revés (byte1|byte0), luego convertir el entero (a octal si lo piden).

Cheatsheet 4 · Assembly y saltos (P3)

Cheatsheet 4 — Assembly del computador básico y saltos (P3)

1. Estructura de un programa

DATA:
  a  5        ; variables (datos) primero
  b  3
CODE:
  MOV A, (a)  ; instrucciones después
  ...

2. ISA básica

  • MOV A, Lit / MOV B, Lit: cargar literal. MOV A, (var): cargar desde memoria (direccionamiento directo).
  • MOV (var), A: guardar en memoria. MOV (B), A: guardar en la dirección que dice B (indirecto).
  • ADD/SUB A, B | A, Lit | A, (var): operaciones ALU. INC/INC (var), DEC, NOT A, A, SHL/SHR A, A, AND, XOR, CMP.
  • PUSH A / POP B: stack. CALL sub / RET: subrutinas (post-I1 probablemente, revisar clase 04).
  • JMP label: salto incondicional. Etiquetas = dirección de la línea.
  • Paréntesis (B) = usar el contenido de B como dirección de memoria.

3. Saltos condicionales — CMP + flags

CMP A, B restaura A − B sin modificar A ni B, y actualiza las flags Z y N.

Salto Condición (flags) Equivalente
JEQ Z = 1 a == b
JNE Z = 0 a != b
JGT Z = 0 y N = 0 a > b
JLT N = 1 a < b
JGE N = 0 a >= b
JLE Z = 1 o N = 1 a <= b
JCR / JOV C = 1 / O(V) = 1 por excepción
  • OJO (error clásico): el salto usa las flags de la operación anterior. Si entre CMP y el salto condicional hay otra instrucción que cambie flags (como JEQ end), el JNE loop evaluará flags equivocadas.

4. Registro Status

Guarda Z, N, C, O. Los saltos leen de ahí. Se conecta a la Unidad de Control.

5. Simulación paso a paso (cómo responder "valores finales")

Para "indique los valores de A y B al finalizar":
1. Haz una tabla de trazado por instrucción: # | Instr | A | B | mem afectada | flags | PC destino.
2. Asigna direcciones de memoria a cada instrucción (primera línea de CODE = dirección 0, RET/saltos de 2 celdas si se indica).
3. Presta atención a: direccionamiento indirecto MOV A,(B) (lee la celda cuya dirección es B), MOV (B), Lit, shifts (bit descartado → flag C), y qué instrucción queda al vuelo tras un RET.
4. El stack: PUSH decrece SP y guarda; RET carga en PC el tope del stack (¡puede saltar a un valor inesperado si el stack fue modificado!).

Ejemplo de error frecuente (I1 2024-1)

En una subrutina, MOV (B), 14 escribió sobre la celda que contenía la dirección de retorno del RET. Resultado: el programa no volvió a MOV B, (res) sino a otra instrucción, dejando B con el valor calculado adentro. → Verificar siempre si el código pisa el stack/retorno.

Cheatsheet 5 · Microarquitectura (P3, bonus)

Cheatsheet 5 — Microarquitectura / señales de control (P3, bonus)

Solo si sobra tiempo (es lo más difícil y de menor retorno en 1-2 días).

1. Idea

Cada instrucción = una combinación de señales de control que la Unidad de Control activa en un ciclo. Las preguntas típicas piden: agregar una instrucción → modificar el diagrama + entregar la tabla de señales.

2. Señales típicas (diagrama del computador básico)

Señal Función
LA / LB / LPC Cargar registro A / B / Program Counter (1 = activo)
W Escribir en memoria de datos
IncSP / DecSP Incrementar / decrementar puntero de stack
SA (SA0,SA1), SB Selección de entrada de los mux A y B (A, B, LIT, ZERO, DOUT...)
SOP Operación ALU (ADD, SUB, AND, XOR, NOT...)
SAdd Selección de dirección de memoria (LIT, B, SP...)
SDin Selección del dato a escribir en memoria
SPC Selección del mux del PC (siguiente, LIT, DOUT...)
Condición En saltos: la carga de PC depende de una flag (ej. Z=1)

Convención de respuestas: en cargas/escrituras poner 1/0; en selecciones poner el nombre de la entrada (o - si no afecta).

3. Patrón para agregar una instrucción

  1. Identifica qué señal falta (ej. cargar un registro nuevo, seleccionar una entrada nueva en un mux).
  2. Modificación típica:
  3. Nuevo registro R → nueva señal de carga LR.
  4. Nueva entrada a un mux → ampliar selector (ej. SPC de 1 a 2 bits, SB agregando SB2).
  5. Conectar salida ALU / memoria / SP al mux correspondiente.
  6. Completa la fila de señales: para instrucciones simples = 1 ciclo (La/Lb/Lpc = 0, salvo que cargue algo; W = 0 salvo que escriba memoria).
  7. A veces la instrucción se puede hacer sin modificar hardware con 2 ciclos (ej. MOV B,((Dir)) = MOV B,(Dir) + MOV B,(B); o NEG A = NOT + ADD A,1). ¡Indícalo si aplica!

4. Ejemplo resuelto (patrón)

Instrucción JMP B (I1 2022-1):
- Modificación: conectar salida del registro B a una entrada del Mux PC (o conectar salida de la ALU al Mux PC). Si el mux ya no tiene entradas → ampliar SPC.
- Señales: LA=0 LB=0 LPC=1 W=0 IncSP=0 DecSP=0 SA=ZERO SB=B SOP=ADD SAdd=- SDin=- SPC=B.

Instrucción DEC B (I1 2022-1), sin modificar hardware, 1 ciclo:
- Seleccionar B en el mux A, ADD con LIT -1, cargar B: LA=0 LB=1 SA=B SB=LIT SOP=ADD.

4b. Ejemplos de la I1 real de 2026-1

  • SUB B,B,A (B ← B − A): requiere conectar B al Mux A y A al Mux B (ampliar SA y SB, y la salida de la Control Unit). Señales: LA=0 LB=1 LPC=0 W=0 SA=B SB=A SOP=SUB SAdd=-.
  • ADD (B),Lit (Mem[B] ← Mem[B] + Lit): conectar la salida de Data Memory (DOUT) al Mux A (ampliar SA). Señales: LA=0 LB=0 LPC=0 W=1 SA=DOUT SB=LIT SOP=ADD SAdd=B.
  • RESTART (PC ← 0): sin modificar hardware; usar LPC=1 con literal 0 (SPC=LIT, LIT=0), o agregar señal RPC al reset del PC.
  • Observación: si el mux no tiene entradas libres, se amplía su selector (SA/SB/SPC a más bits) y la salida de la Control Unit crece en esa cantidad de bits.

5. Errores comunes a evitar

  • Dejar Lpc=1 por defecto en instrucciones que no saltan (debe ser 0).
  • No activar W cuando se escribe memoria (y al revés).
  • Olvidar indicar la condición en saltos condicionales (LPC depende de Z/N, no es 1 fijo).
  • Modificar hardware cuando no hace falta (indicar los 2 ciclos con señales existentes).

1. Tabla de saltos (CMP A,B → a − b)

JGT   Z = 0 y N = 0  a > b
JLT   N = 1        a < b
JGE   N = 0        a >= b

2. Compuertas lógicas (salida = 1 cuando…)

NOT A      → A = 0
A AND B    → ambas = 1
A OR B     → al menos una = 1
A XOR B    → son distintas
NAND       → NO(AND): 0 solo si ambas = 1
NOR        → NO(OR): 1 solo si ambas = 0

3. Flags de la ALU + overflow

Z = resultado es 0
N = resultado es negativo (MSB)
C = carry de salida (o bit descartado en shift)
O/V = overflow (fuera de rango con signo)

Overflow (con signo), 4 casos:
  A≥0, B≥0 → O=1 si A+B < 0
  A<0, B<0 → O=1 si A+B ≥ 0
  A≥0, B<0 → O=1 si A−B < 0
  A<0, B≥0 → O=1 si A−B ≥ 0

Rangos: n bits sin signo [0, 2^n −1]; con signo C2 [−2^(n−1), +2^(n−1) −1] → 8 bits: −128..127.

4. Potencias de 2 (referencia rápida)

2^0  1      2^6   64     2^12  4096
2^1  2      2^7  128     2^13  8192
2^2  4      2^8  256     2^14 16384
2^3  8      2^9  512     2^15 32768
2^4 16     2^10 1024     2^16 65536
2^5 32     2^11 2048

5. Recetas de conversión

C2        : negar todos los bits + 1
bin→hex   : agrupar de a 4 bits (desde la derecha)
bin→oct   : agrupar de a 3 bits
dec→bin   : divisiones por 2, restos al revés
base 8→4  : cada dígito oct → 3 bits; agrupar de a 2 bits
            (agregar 0 a la izquierda si falta); cada par → dígito base 4
extender bits (8→16): positivo → 0s; negativo → 1s

6. Minterm / Maxterm (de tabla a circuito)

Minterm: fila con 1 → AND de variables (NOT las que valen 0); OR todo
Maxterm: fila con 0 → OR de variables (NOT las que valen 1); AND todo

7. Sumador / Restador

Half Adder : S = A XOR B ; Cout = A AND B
Full Adder : S = A XOR B XOR Cin ; Cout = c1 OR c2
Sumador-Restador: Cin=0 → A+B ; Cin=1 → A−B (negar B + 1)

CARA 2

8. Contadores con flip-flops D

Incrementa (Q' = siguiente estado):
  Q0' = NOT Q0
  Q1' = Q0 XOR Q1
  Q2' = (Q0 AND Q1) XOR Q2

Decrementa:
  Q0' = NOT Q0
  Q1' = Q0 XNOR Q1

Con condición A (inc solo si A=1): Q' = (A AND inc) OR (NOT A AND Q)
  → equivale a un MUX con A como selector.

9. Almacenamiento

Latch RS : S=1→Q=1 ; R=1→Q=0 ; S=R=1→mantiene ; S=R=0→indef.
Latch D  : D=C=1→1 ; D=0,C=1→0 ; C=0→mantiene
Flip-Flop D: cambia SOLO en flanco de subida (↑): Q(t+1)=D
Registro : N flip-flops D (N bits) + carga (L) + reset (R)
Contador : registro + señal Up/Down (+1 / −1 por flanco)

Endianness (int multibyte en memoria):
  Big   : byte MSB primero (dir. más baja)
  Little: byte LSB primero
  Ej. 0x0FA71D23: little → 23 1D A7 0F

10. ISA del computador básico

Segmentos: DATA (variables) luego CODE (instrucciones)

MOV A, Lit | MOV B, Lit          cargar literal
MOV A, (var) / MOV (var), A      memoria, direccionamiento DIRECTO
MOV A, (B)  / MOV (B), A         memoria, dirección en registro B (INDIRECTO)
ADD/SUB A, B | A, Lit | A, (var) operaciones ALU (resultado en A)
INC / DEC / NOT A,A / SHL/SHR A,A / AND / XOR / CMP
PUSH A / POP B                   stack
CALL sub / RET                   subrutinas
JMP label                        salto incondicional
Parentesis (B) = usar contenido de B como dirección

11. Señales de control (microarquitectura)

LA / LB / LPC   : cargar registro A / B / PC (1 activo)
W               : escribir en memoria de datos
IncSP / DecSP   : +1 / −1 al puntero de stack
SA (SA0,SA1)    : selección Mux A (A, B, ZERO, LIT…)
SB (SB0,SB1,SB2): selección Mux B (B, DOUT, LIT…)
SOP             : operación ALU (ADD, SUB, AND, XOR, NOT…)
SAdd            : dirección de memoria (LIT, B, SP, B+offset…)
SDin            : dato a escribir en memoria
SPC             : selección Mux PC (next, LIT, DOUT, RA…)
Condición       : saltos → LPC depende de flag (Z/N), no fijo 1

Instrucciones básicas (referencia):
  MOV A, Lit : LA=1, SA=ZERO, SB=LIT, SOP=ADD
  ADD A, B   : LA=1, SA=A, SB=B, SOP=ADD
  JMP        : LPC=1, SPC=LIT
  JEQ        : LPC=1 solo si Z=1, SPC=LIT
